## Important Directories

| Directory | Purpose |
|---|---|
| `/` | Root of the filesystem |
| `/etc` | Configuration files |
| `/var` | Variable data and logs |
| `/tmp` | Temporary files |
| `/usr` | Programs and libraries |
| `/opt` | Optional/third-party software |
| `/root` | Root user's home directory |
